Perimeter Telemetry Pipeline: syslog-ng & Suricata to Wazuh

syslog-ng Advanced Engine

pfSense runs syslog-ng to tap both kernel firewall drop logs and Suricata IDS EVE JSON telemetry, routing them over encrypted transport directly into the SIEM manager.

# syslog-ng destination & route mapping from pitasense backup
destination d_wazuh {
    network("192.168.3.11" transport(tcp) localip(192.168.3.2));
};

source s_pfsense_logs {
    file("/var/log/filter.log");
    file("/var/log/system.log");
};

source s_suricata {
    file("/var/log/suricata/suricata_em142983/eve.json" follow_freq(1) flags(no-parse));
};

log { source(s_pfsense_logs); destination(d_wazuh); };
log { source(s_suricata); destination(d_wazuh); };

Samba-DC on Linux: GPO Deployment & Enterprise Management

Identity & Access Management

A full Active Directory Domain Controller deployed on Ubuntu Linux using Samba 4. Windows Server operates as an infrastructure member server, while domain workstations receive continuous policy enforcement from the Linux SYSVOL share.

1. Samba AD DC smb.conf (pitaworld.pita)

[global]
    netbios name = PTASDC
    realm = PITAWORLD.PITA
    workgroup = PITAWORLD
    server role = active directory domain controller
    dns forwarder = 192.168.3.2
    idmap_ldb:use rfc2307 = yes

[sysvol]
    path = /var/lib/samba/sysvol
    read only = No

[netlogon]
    path = /var/lib/samba/sysvol/pitaworld.pita/scripts
    read only = No

2. Group Policy (GPO) Architecture & Client Verification

GPOs managed from RSAT are stored within the Samba SYSVOL share, enforcing audit telemetry and endpoint hardening across domain-joined Windows machines:

  • Audit Process Creation (Event 4688): Enforces command-line argument logging across endpoints, generating high-fidelity telemetry for Wazuh.
  • LAPS Policy: Rotates local administrator passwords automatically, preventing lateral credential harvesting.
  • Verification: Running gpresult /r on client endpoints confirms policy retrieval from PTASDC over port 445:
